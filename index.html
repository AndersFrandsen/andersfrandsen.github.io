Gravimetric Espresso Mod

A personal project modifying my Rocket Espresso machine into a gravimetric (brew-by-weight) machine — enabling precise measurement and control of espresso extraction for more consistency in every shot.

Features

  • Brew-by-weight control: monitors the shot's weight in real time and automatically stops extraction once the target ratio is reached.
  • UI: a responsive TFT touchscreen interface showing shot weight, extraction time, and shot settings.

The reference cup was also used for loadcell calibration. The extraction here is 36.64 g — close to the 36 g target (18 g dose at a 1:2 ratio).

Hardware used

  • MCU: Nordic nRF52840
  • TFT touch: Adafruit 2.8" Capacitive
  • SparkFun 500 g loadcell
  • NAU7802SGI 24-bit ADC
  • TCK108AF load switch IC

Software and tools

  • Zephyr RTOS for firmware
  • KiCad for PCB design

Current limitations

The E61 group head lever not only activates the pump via a switch, but also mechanically opens the pre-infusion valves. Because of this, the lever must still be operated manually for the controller to work. To make the process fully automatic, the lever would need to be actuated too — by a DC motor, servo, or similar mechanism.

Matter over Thread Door Sensor

A battery-powered Matter-over-Thread door sensor acting as a Sleepy End Device (SED). Commissioning is validated end-to-end with Home Assistant on a Raspberry Pi running an OpenThread Border Router via an nRF52840 dongle.

Boolean State reports whether the door is open or closed. StateValue is false = closed, true = open.

Power Consumption

Power measurements taken with a Nordic Power Profiler Kit (PPK).

Idle — ICD SIT (Short Idle Time) mode

As a Sleepy End Device polling on a 15 s interval, the average current over 1 minute is 7.47 µA (max 9.11 mA during radio activity).

Measuring between the polling spikes gives 5.84 µA, which is closer to the true idle floor and what the average would be in ICD LIT (Long Idle Time) mode (WIP).

Door open

While the door is open the average current is 2.51 mA, driven mainly by the status LED being on.

Hardware used

Endpoint Device

  • Platform: Nordic nRF52840-DK (development)
  • MS88SF2 module (for PCB)
  • Adafruit magnetic reed switch

The PCB v1.0 uses a MS88SF2 module, a CR2032 coin cell, a 14-pin STDC14 header for J-Link flashing/debugging.

Thread Border Gateway

  • Raspberry Pi 4B
  • Nordic nRF52840 Dongle

Preparing the dongle as a Radio Co-Processor (RCP) is straightforward — follow this guide. Once the firmware is installed, set up Home Assistant on the Raspberry Pi, connect the USB dongle, then install both the OpenThread Border Router (OTBR) and Matter Server add-ons to enable Thread and Matter support.
